# V1-V6 axis note
Date: 2026-09-18

Intended axes
V1 command: tell the model what to do
V2 factual update: add a later-looking fact
V3 hedge: same fact, weaker wording (may / limited)
V4 booster: same fact, stronger wording (completely / none left)
V5 source cue: same fact plus a fake office memo
V6 short factual: same fact as V2, similar length

What the runs actually showed
V1 rejected
V2/V6 adopted on document summary
V3 usually rejected
V4 mixed, weak
V5 unstable for the judge, often rejected by the model

Citation status
Hyland 1998, Hovland 1953, Petty and Cacioppo 1986 were listed as homework.
They are not yet verified from the PDFs in this repo.
Until that check is written, call V1-V6 "wording variants", not "rhetoric treatments".
