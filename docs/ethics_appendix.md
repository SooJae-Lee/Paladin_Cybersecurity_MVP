# Ethical Considerations

Purpose. This project reproduces injection against a local mock-tool agent to measure channel effects. It is not an exploit kit for production systems.

Harm reduction. Tools are fake. No real email, calendar, payment, or filesystem side effect is executed. Payloads rewrite a summary of a synthetic earnings note. They do not include malware or credential theft.

Disclosure. Attack strings are short factual paraphrases of a research condition, not a packaged worm.

Release. A public repository must not be cited with real names in a double-blind PDF. Artifacts for review should be an anonymous mirror. Do not publish live API keys.

Human subjects. No user study. No personal data.

Misuse. Results should not be read as a recipe to jailbreak deployed agents. The finding is that document-like framing can beat command-like framing on this mock task.
