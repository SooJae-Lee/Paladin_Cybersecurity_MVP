# Ethical Considerations

This work reproduces prompt-injection and tool-hijacking behaviors only inside a research testbed.
The tools are mocks. No production calendar, mailbox, repository, or customer system is connected.
Payloads rewrite a fictional earnings summary. They do not include malware, exploit code, or instructions for harming people.

The repository and paper describe attacks so that defenses can be measured.
We do not release a turnkey exploit against a live MCP server.
Any public artifact should keep API keys out of git and should label injected text as an experimental condition.

Human review used existing model outputs. No additional personal data was collected.

이 연구는 연구용 테스트베드에서만 공격을 재현한다.
도구는 mock이며 실제 캘린더·메일·코드저장소에 연결하지 않는다.
페이로드는 가상 실적 요약문을 바꾸는 수준이다.
공개 목적은 방어 측정이며, 실제 MCP 서버용 공격 도구를 배포하지 않는다.
