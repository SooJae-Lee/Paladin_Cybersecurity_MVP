Dear Editor,

Please consider our manuscript, “Measuring Channel-wise Tool Hijacking and Context Manipulation in Tool-Calling Agents.”

The paper measures how a tool-calling agent can be steered when untrusted tool outputs or retrieved documents are treated as evidence. We compare four injection channels on a Claude agent and report that factual retrieved-document text is more effective than explicit commands. We also include a first runtime detector and state clearly that stronger detection of document-style poisoning is future work.

This is an original measurement study and has not been published elsewhere.
