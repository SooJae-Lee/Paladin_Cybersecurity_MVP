# Submission checklist

Paper type: measurement, not detector.

Must have
- [x] one task, one payload family
- [x] four channels
- [x] Korean and English
- [x] n=10 table
- [x] label correction note (keyword vs judge)
- [x] limitations
- [x] related work (4 papers)
- [x] scope page

Must not claim
- [ ] F1=1.0 as a scientific result
- [ ] live MCP evaluation
- [ ] a trained detector
- [ ] statistical significance from n=10

Before any submission
- [ ] pick venue and template
- [ ] anonymize names and repo
- [ ] replace keyword tables with canonical judge table
- [ ] spot-check 16 judge labels
- [ ] second model remains appendix unless rerun under the same judge
